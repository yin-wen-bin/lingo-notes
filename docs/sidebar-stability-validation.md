# 侧栏连接与阅读防抖验证

2026-11-23。用户报告 1.0.1 侧栏过一段时间会抖动。本次保持版本 1.0.1、cloud/5 和扩展 ID，在 codex/sidebar-stability 隔离目录基于已整合源码快照实施。

## 原因与修复

代码中没有 location.reload、tabs.reload 或 runtime.reload 等保活重载。可复现的正文抖动来自普通文档流顶部的连接卡：断开时显示、就绪后隐藏，推下再拉回正文。旧码合成复现中，阅读目标 top 从 131px 移到 201.75px，28 个动画帧中有 24 帧发生位移。

另外两条无意义重绘分别为：相同版本的队列同步重新应用材料快照，替换文字节点并丢失选择；无活动流时相同 processing 记录的 GET 每次重建讲解，停止语音并重新挂载控件。普通已完成记录不走该轮询，因此不将它单独归因为所有闲置抖动。

- 短暂连接恢复延迟 1.5 秒提示，成功就绪会撤销计时器；持续连接失败仍显示重试入口。提示使用固定底部状态卡，脱离正文布局，不改变阅读位置或遮住顶部导航。持续离线时状态卡可能覆盖底部少量内容，这是当前方案的明确取舍。
- 队列材料按账号、任务、阶段、原文、上下文、来源、绑定、语言和错误状态比较；没有变化就不调用 applyContent。相同快照仍进行确认、通知、只读恢复及排队协调，不丢弃连接恢复所需的同版本回执。
- 完全相同的记录 GET 不重建讲解或控件，保留当前预览和文本选择；真实记录、结果、修订或终态变化仍更新。显式切换任务或返回内容仍强制恢复界面。
- UI 文字和显隐属性仅在变化时写入。没有新增页面刷新、永久保活、网络计时器、模型请求或公共接口。
