# 历史列表展示调整

2026-11-21。用户选定日期分组列表草图，范围仅为扩展历史列表、搜索栏及其本地资源；不改云端数据结构、不重写笔记、不调用模型。

## 实现

- 以记录的 `local_date` 分组，按北京时间显示今天/昨天；其他日期按界面语言格式化，跨年保留年份。加载更多时同一天只有一个组。
- 查询材料保持 16px、最多两行，日期与状态 14px。取消独立卡片框，改为浅分隔线、整行悬停/聚焦背景。
- 行尾使用常显删除图标，44×44 点击区域，支持键盘和本地化可访问名称；继续使用原删除确认与云端删除流程。
- 截图显示本地图片图标与文字标记；空材料显示截图笔记。完成记录不重复显示状态，未完成/失败状态继续可见。
- 搜索框含搜索图标，与深绿查询按钮同高 44px；按钮 15px，输入 16px，保持 Enter 查询、清空恢复原列表。
- 中日英切换只更新界面绑定，不替换搜索输入、翻译原文或重新请求列表。
- 图标来自 Heroicons v2.2.0，原 MIT 许可证随扩展打包。构建和商店包使用精确文件白名单；不放宽其他资源检查。
