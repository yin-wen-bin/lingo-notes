# Lingo Notes

**随手记，然后让 AI 帮你整理和复习。**

在 Chrome 阅读英文或日文时，划词、输入文字或框选截图，获得讲解和例句；保存的笔记可以在手机上回看，并按间隔复习计划再次遇见。

项目由 **Chrome 扩展 + Supabase 云端 + 手机 PWA** 组成。即时讲解仅接入 **DeepSeek**，使用用户自己的 API Key；每日复习直接复用已保存的学习内容，不额外调用模型。

[学习中心](https://lingo-notes.pages.dev) · [使用支持](https://lingo-notes.pages.dev/support) · [隐私说明](https://lingo-notes.pages.dev/privacy) · [验收与发布状态](docs/release-status.md)

> 当前为邀请试用版，需要受邀账号和自己的 DeepSeek API Key。Lingo Notes 当前不收软件使用费，模型费用由 DeepSeek 按用户账户用量收取。Chrome 商店尚未上架，首次计划采用 Unlisted 链接安装。

## 可以做什么

| 场景 | 当前功能 |
| --- | --- |
| 随手查词句 | 划词后点击“用 Lingo Notes 学习”直接开始讲解，连续划词依次排队；也可手动输入。自动提取可用上下文，保留原标签页和阅读位置。 |
| 用图片学习 | 在网页上框选截图或选择图片，预览确认后上传；识别文字可校正，再生成讲解。确认截图随笔记保存。 |
| 选择讲解语言 | 中文、日本語、English 三选一，按账号保存；扩展界面随选择切换。同语言的例句解释提供简明释义。 |
| 边生成边阅读 | 流式展示核心内容，再补齐完整讲解；每次选择 1–3 个学习点，每点提供 3 个例句及译文。 |
| 听发音 | 单词和例句均可播放，点击同一按钮停止；读音标注使用音标或假名。 |
| 找回笔记 | 日期分组的历史列表支持搜索、查看、修订和删除；返回列表时保留搜索、分页和滚动位置。 |
| 按自己节奏复习 | 每日数量可输入 1–100 张；词汇和语法可标记“已记住”，也能撤销。 |
| 手机上阅读 | PWA 展示笔记、截图和复习卡片，支持手机通知，云端调度不要求电脑开机。 |

扩展顶部常驻 **新建 / 历史 / 设置**。一体输入区将文字、截图、选图和讲解语言放在一起，下方是全宽“讲解”按钮。进入历史或设置时保留未发送的草稿；点击“新建”会打开空白输入。

连续划词依次处理，可在状态条查看当前查询或清空等待项。关闭所有侧栏会暂停，重新打开后先核对已有请求，再继续未发送的内容；完全退出浏览器会结束等待队列。结果未能确认时只核对已有记录，不自动重发。

设置支持快速与思考两种讲解模式，以及“雅致清晰、手写感、书卷感、清爽自然”四套字体。默认快速模式和雅致清晰；思考模式通常更慢、用量更多，仍可能出错。

## 开始使用

1. **准备账号。** 通过邀请渠道开通 Lingo Notes 账号并设置密码；安装扩展不会自动获得账号。
2. **登录并设置 Key。** 在扩展设置中登录，填写自己的 DeepSeek API Key。Key 由云端 Vault 加密保存，保存后界面只显示状态和末四位。
3. **创建笔记。** 划词后点击“用 Lingo Notes 学习”直接开始；手动输入仍点击“讲解”，截图仍需预览和识别文字确认。未登录或没有 Key 时保留选词并引导设置，设置完成后再手动点击“讲解”。已保存内容可从历史查看。
4. **在手机上阅读。** 用 iPhone Safari 打开[学习中心](https://lingo-notes.pages.dev)，通过分享菜单添加到主屏幕，再从主屏幕图标打开并登录。
5. **开启复习提醒。** 在手机设置页启用每日复习和手机通知，允许系统权限，可用“发送测试通知”检查设备。每日数量也可在扩展设置中修改。

手机端用于阅读、复习和设置。返回时恢复原来的阅读位置与搜索，最近已读的笔记、历史页和复习卡可在同一设备重开时先读取本机缓存。登录会话须有效，新内容、截图和修改操作需要联网。当前主要验证 Windows Chrome 与 iPhone。

## 每日复习如何安排

每天北京时间 **07:00 起**，云端从已保存的学习点中挑选到期内容，优先处理逾期项；无到期内容不发送空提醒。每日上限默认 **5 张**，可自行输入 **1–100**。数量修改对新生成的批次生效，已经生成的当天批次不重新排列。

| 操作 | 对复习进度的影响 |
| --- | --- |
| 点击“已复习” | 确认完成当前一轮，安排下一轮。重复点击不会多推进一轮。 |
| 点击“已记住” | 该学习点退出后续复习，原笔记保留；可立即撤销，或到原笔记中撤销。 |
| 收到通知或打开卡片 | 不自动算作完成复习，也不算已经掌握。 |

默认共 **5 轮**。正常完成时对应首次学习后的第 **1、3、7、14、30 天**；第一轮之后，按实际完成日期分别间隔 **2、4、7、16 天**。错过一天会顺延，不会一次集中补完多轮。五轮完成后结束这轮计划。

相同账号内内容一致的学习点共享进度和“已记住”状态，不同词义分别安排。固定间隔用于帮助形成复习节奏，不是对个人遗忘速度的精确预测。通知实际送达仍取决于网络、手机权限和推送服务，当前每个账号使用一台主要通知设备。

## 一键部署自己的实例

Windows 上登录 Supabase CLI 和 Wrangler，准备一个专用空 Supabase 项目，并选好 Cloudflare Pages 项目名。安装依赖后运行：

```powershell
npm run deploy:self-host -- --supabase-ref <项目ID> --pages-project <项目名> --owner-email <邮箱>
```

命令部署数据库、函数、复习调度和手机学习中心，并生成连接该实例的自用扩展。首次部署前可以追加 `--dry-run` 核对目标。[自部署指南](docs/self-host.md)

## 开发与构建

需要 Node.js **24.16.0–24.x**、npm，以及浏览器测试使用的 Microsoft Edge。Windows 是当前 CI 环境。

```powershell
npm ci
npx playwright install msedge
npm test
npm run typecheck
npm run build -- --allow-unconfigured
```

全新克隆未配置云端时，最后一条命令生成检查构建，产物为 `dist/extension` 和 `dist/pwa`，不能作为正常连接服务的安装包。`--allow-unconfigured` 允许配置缺失，并不会忽略本机已有配置。测试使用合成接口和临时数据库，不调用真实 DeepSeek、不访问个人学习记录。

维护者可复制 `config/cloud.public.example.json` 为被 Git 忽略的 `config/cloud.public.json`，填写项目 URL、publishable key、VAPID 公钥及 PWA URL，再运行 `npm run build`。这些都是公开客户端参数，**不要填入 service-role、DeepSeek Key 或 VAPID 私钥**。

开发版加载方式：打开 `chrome://extensions/`，启用开发者模式，选择“加载已解压的扩展程序”，定位到已配置构建的 `dist/extension`。更新文件后点击该扩展的“重新加载”。商店版本的打包、来源与 ID 校验见[商店发布说明](docs/store-release.md)。

## 架构与维护

```text
Chrome 扩展 ──┐
             ├─ Supabase Auth / Edge Functions ─ Postgres / 私有 Storage / Vault
手机 PWA ────┘                    │
                                  └─ DeepSeek（用户自己的 Key）

云端 Cron ─ 到期学习点 ─ 每日复习批次 ─ Web Push ─ 手机 PWA
```

- 账号采用邀请制邮箱密码登录，无公开注册，不发送登录验证码；初次设置或忘记密码由管理员提供一次性设置入口。
- 截图仅在确认后上传；各账号的笔记、图片和复习状态隔离。手机端按账号保存最近已读文本，最多 7 天和 5 MB；退出或切换账号时清理，截图继续联网读取。
- 模型取消或连接中断不自动重发；生成结果只有经过校验和持久化后才标记完成。
- 复习只使用手机推送；当前没有邮件渠道、Pages、WorkBuddy 或本地桥接依赖。
- 发音使用浏览器系统语音服务，优先本地语音，但不保证所有发音都离线。

## 验证与限制

2026-11-27，cloud/6 通过 **237 项本地自动测试**、类型检查和已配置构建。已部署学习中心与云端接口，本地扩展使用原 1.0.1 加载目录。iPhone 已验证历史返回和手动通知，Chrome 已验证侧栏原生拖宽和拖窄。自然晨间锁屏推送仍待真机验证。各项证据见[发布与验收状态](docs/release-status.md#cloud6-手机阅读例句与侧栏修复)。GitHub 按提交运行独立的 [Windows CI](https://github.com/yin-wen-bin/lingo-notes/actions)。

当前商店版本、审核进度和实机验收记录见[发布状态](docs/release-status.md)。自建实例需要在自己的设备上完成通知测试。

AI 讲解可能有误，尤其是日语活用、读音和敬语；请结合可靠资料核对。不要提交不希望交给云端服务处理的网页内容或截图。
