# 审核测试步骤

本文件没有有效凭据。需要限制访问的扩展可在 Chrome Web Store 的 Test instructions 后台提供审核账号与操作说明；该入口与公开源码分开。[官方说明](https://developer.chrome.com/docs/webstore/cws-dashboard-test-instructions)

## 提交人准备（当前待完成）

用户已明确本轮先完成安装包与发布材料，暂没有审核专用 Key。以下独立账号/Key均待配置；不使用个人 Key 补位，不提交完整功能审核。

- [ ] 建立只含合成内容的独立审核账号；不要使用项目所有者或日常用户账号。
- [ ] 通过管理员流程预先设置其密码，并验证有效期覆盖审核时间。
- [ ] 该账号绑定独立、额度受控且可撤销的测试 DeepSeek Key，确保审核可执行完整文字/OCR流程。未经授权不创建账号、不充值、不调用模型。
- [ ] 只在商店后台私有 Test instructions 提供账号密码；模型 Key 预绑定，不把 Key 本文或公开截图中展示。
- [ ] 后台另填失效/访问问题联系渠道；审核结束后按实际安排撤销测试凭据。

后台专用字段模板（占位符不是有效账号）：

```text
审核账号：<在商店后台私下提供，不提交 Git>
审核密码：<在商店后台私下提供，不提交 Git>
测试 Key：由发布者预绑定到独立审核账号，不要求审核者购买或提供自己的 Key
联系渠道：wenbinyin@gmail.com
```

## 审核者操作说明

前置条件：桌面 Chrome 116 或更高版本、互联网连接、上述受邀测试账号。扩展免费安装，正式用户的模型请求由各自 DeepSeek Key 计费。当前不开放自行注册。

1. 安装待审扩展，点击工具栏 Lingo Notes 图标打开侧栏；在菜单“连接与设置”输入测试邮箱和密码。测试账号需事先完成开通，登录不依赖验证码邮件。
2. 在普通 HTTPS 网页选择英语文字，右键选择 Lingo Notes 学习入口。侧栏显示草稿；展开“材料详情”检查上下文和来源。此时尚未请求模型。
3. 也可直接在输入框填写 `Small steps make a difference.`，点击“讲解”。处理中逐步显示内容，完成后显示学习笔记、学习点与每点三条例句。点击读音旁或例句后的发音按钮，再次点击停止。没有系统对应语音时会给出提示。
4. 返回普通网页，点击“截图”，拖动框选一小段文字。先检查区域预览及上传说明，点击“取消”应退出且不发送；再次框选，点击“确认识别”，校正识别文字，再点击“确认讲解”。这些确认动作会产生测试 Key 的实际 API 用量。
5. 点击“历史”，查询刚才的记录；清空搜索应恢复列表。打开一条完整笔记，截图记录可在材料详情查看原图。
6. 删除一条合成笔记，确认提示后检查历史中已移除。不要删除其他账户或真实用户内容。
7. 在“连接与设置”切换字体，检查界面即时变化及重开保留；快速与思考模式由用户主动选择，后续新讲解才生效。
8. 退出登录并重新打开侧栏，检查草稿和旧账号内容不可继续读取。重新登录后，未删除的云端笔记仍可查询。

受限页处理：`chrome://` 页面及 Chrome Web Store 页面不支持网页注入/框选；请换普通网页重新点击扩展图标，或使用菜单“选择图片”。不要为测试授予全部网站访问权限。

配套 PWA：它提供云端笔记阅读和最多五张每日精选卡片；手机推送需要在支持的手机安装 PWA 并授权。当前扩展审核不应把桌面截图或模拟 UI 当成手机定时送达证据。
