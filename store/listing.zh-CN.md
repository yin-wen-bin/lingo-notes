## 名称与简短说明

名称：Lingo Notes

简短说明：随手记，然后让AI帮你整理和复习。划词或确认截图，获取英语、日语的中文讲解并保存学习笔记。需要受邀账号和自备 DeepSeek API Key。

语言：简体中文。分类：在后台现有分类中选择与外语学习最接近的项目，提交前核实。

## Single purpose

帮助中文使用者把网页上遇到的英语和日语转为可回看的外语学习笔记：用户主动选词、输入文字或确认截图后，在侧栏查看中文讲解、读音和例句，并查询或删除自己的笔记。

## 详细说明

Lingo Notes 让你在阅读网页时，随手记下遇到的英语和日语。

划词后使用右键菜单，或在侧栏输入文字，点击“讲解”即可查看中文释义、词汇或语法重点、读音及例句。扩展会尝试从当前页面提取附近句子，帮助模型理解语境；可以在“材料详情”查看附带材料。

支持在网页上框选截图，也可选择本地图片。截图先预览，点击“确认识别”后才发送并保存；识别文字可校正，再确认生成讲解。

主要功能：

- 英语、日语的中文讲解，以及带译文的例句。
- 单词和例句发音，点击播放，再次点击停止。可用语音取决于浏览器和系统。
- 云端保存学习笔记及确认截图；历史支持搜索、打开和删除。
- 快速、思考两种讲解模式，由用户选择；思考模式通常等待更久、消耗更多模型额度。
- 手写感、书卷感、清爽自然三套字体，按账号同步。
- 配套网页/PWA 学习中心可阅读笔记和每日精选复习。手机通知需要单独安装 PWA、授权通知并启用提醒，不由扩展直接发送手机通知。

使用条件与费用：

当前为邀请制版本，需要管理员开通 Lingo Notes 账号，暂不提供公开注册。安装扩展不会自动获得账号。先通过管理员提供的一次性入口设置密码，再在扩展登录。

扩展免费安装。学习请求需要你自己的 DeepSeek API Key；模型用量及费用由 DeepSeek 直接收取，不使用 ChatGPT、Codex 或 WorkBuddy 的订阅额度。Key 加密保存在云端，不会回显。查询和云端历史需要网络。

数据与使用边界：

只有主动确认的学习材料会提交到云端。文字讲解会发送输入及提取的上下文；页面标题与清理后的来源链接随笔记保存。确认截图会保存到私有云端，并发送给 DeepSeek 识别。请在隐私政策中查看数据处理、删除和服务提供方说明。

AI 讲解与识别可能出错。取消已经发送的模型请求不保证撤销已经发生的费用。删除笔记会移出后续复习，已发送的通知及已有备份不追溯删除。
