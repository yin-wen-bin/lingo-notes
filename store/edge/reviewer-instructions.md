# Edge 私有审核说明模板

审核账号和密码只填写到 Partner Center 的私有审核说明。使用原有独立审核账号和额度受控的专用 DeepSeek Key。提交前核对登录、Key 已配置状态和官方扩展来源。现有审核账号已预绑定模型 Key 时，审核人员无需填写自己的 Key。

```text
Product: Lingo Notes, version 1.0.1.
Invited reviewer email: <REVIEW_EMAIL>
Reviewer password: <REVIEW_PASSWORD>
A dedicated DeepSeek test key is preconfigured. Please use synthetic content.
Companion website: https://lingo-notes.pages.dev/
Support: https://lingo-notes.pages.dev/support
Privacy policy: https://lingo-notes.pages.dev/privacy
```

1. 安装待审扩展，展开侧栏，在设置页登录。查看连接状态和 Key 状态，拖动侧栏边界核对布局。
2. 在普通 HTTPS 网页选中英文短句，通过右键启动讲解。再选择另一段文字，检查请求按点击顺序进行。完成后可从历史打开合成笔记。
3. 在新建页输入 `毎日少しずつ学びます。`，选择英语讲解。例句原文及发音应为日语，讲解和例句译文应为英语。语法说明标题以文字呈现，例句仍有发音控制。
4. 框选合成内容或选择合成图片。检查预览、取消及确认识别流程。校正文字后再确认讲解。
5. 从历史搜索、打开并返回，核对位置恢复。删除自建的合成笔记，核对列表结果。练习点可标记为已记住并撤销。
6. 在学习中心打开并返回一条笔记，检查原位置。已登录用户可重开并阅读最近缓存过的内容。系统语音、通知及自然推送的真机结果分别记录。

在审核期内保留私有测试资料，通过商店后台回读实际提交状态。[Microsoft 审核说明和提交](https://learn.microsoft.com/en-us/microsoft-edge/extensions/publish/publish-extension#step-8-enter-certification-testing-notes-and-submit-the-extension)
