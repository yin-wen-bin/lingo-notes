# Lingo Notes on Microsoft Edge

## Short description

Learn English and Japanese from web pages, save notes, and review later. Requires an invited account and your own DeepSeek API key.

## Description

Lingo Notes helps you learn English and Japanese while reading in Microsoft Edge. Select text and choose “Learn with Lingo Notes” from the context menu to begin. Repeated selections queue in click order. The sidebar keeps drafts and saved notes available while you work, and checks the original request when a connection drops.

You can also enter text manually, select an explanation language, and click Explain. To use a screenshot or a local image, preview it and confirm before uploading. Review and correct the recognized text before requesting an explanation.

- Read explanations in Chinese, Japanese, or English. Examples and pronunciation follow the learning material. The extension's interface follows the chosen explanation language.
- Play pronunciation for words and example sentences. Available voices depend on the browser and operating system.
- Search, revisit, revise, and delete saved notes. Adjust the native Edge sidebar width and choose from four fonts.
- Review saved learning points in the companion website or phone app. Set a daily limit between 1 and 100 cards and mark individual points as reviewed or remembered. Daily review reuses saved content without additional model requests.
- On the phone, return to the same reading position and reopen recently read text, history, and review cards from account-specific local storage. The reading cache retains up to 5 MB for up to seven days. Screenshots still load over the network.

Lingo Notes is an invitation-only trial. The extension is free to install. New explanations and image recognition require your own DeepSeek API key. DeepSeek bills usage directly. AI explanations and recognition can contain mistakes. Check important learning points against reliable references.

Phone notifications require a supported device, the installed phone app, system notification permission, and enabled reminders. You can check the current device connection and send a test notification from phone settings.

When you choose the learning menu item or submit typed text, the extension sends the material and available nearby context to Lingo Notes. Notes include the page title and cleaned source URL when available. Confirmed images are sent after preview. Supabase handles authentication, private records, confirmed screenshots, and protected key storage. DeepSeek processes submitted learning content.
