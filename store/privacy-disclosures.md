# 权限与数据披露填写建议

这是根据当前源码整理的商店后台填写稿，不是已完成的后台声明，也不替代正式隐私政策。提交者应逐项核对实际托管、服务条款与后台类别后确认；真实凭据不得填写到本文件。[官方隐私字段说明](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy)

## 权限说明

| Manifest 项目 | 可填写的用途说明 |
|---|---|
| `contextMenus` | 在用户选中文字后提供“学习”右键入口，把选中文字放入侧栏草稿。打开草稿不会自动调用模型。 |
| `sidePanel` | 在当前网页旁展示学习输入、截图预览、讲解、历史和连接设置，保留原网页。 |
| `activeTab` | 用户点击扩展图标或使用右键入口后，临时访问当前网页以获取选词上下文、标题与来源，以及执行用户发起的截图。扩展没有持续读取全部网站的权限。 |
| `scripting` | 注入包内的页面脚本，查找选词附近可见文字，并显示框选截图遮罩。脚本排除表单输入和隐藏内容，不下载外部脚本。 |
| `storage` | 在 `chrome.storage.local` 保存登录会话；在 `chrome.storage.session` 保存本次浏览器会话的草稿、记录恢复定位和原页面绑定。密码和模型 Key 不写入这些浏览器存储。 |
| `https://brbymnycnxtfchffanvs.supabase.co/*` | 访问固定的 Lingo Notes 后端，用于账号登录、按账号保存和读取学习记录及确认图片、管理加密模型 Key 和用户设置。扩展不直接向 DeepSeek 发请求，由此后端处理。 |

来源：`extension/manifest.json`、`extension/background.ts`、`extension/page.ts`、`extension/panel.ts`、`shared/cloud-client.ts`。发布包若更换后端项目，必须同时核对 host permission、CSP、公开构建参数和本说明。

## 数据清单与后台类别建议

| 数据 | 目的与去向 | 后台披露建议 |
|---|---|---|
| 账号邮箱、账号 ID | Supabase Auth 登录与账号隔离 | 个人身份信息 |
| 密码、访问/刷新令牌、用户 DeepSeek Key | 密码发往 Supabase Auth；会话令牌保存在本设备；模型 Key 发往后端并存 Vault，用于调用 DeepSeek | 身份验证信息；即使密码不落本地，也不应声明未处理 |
| 输入/选中文字、自动提取的前后句、OCR 与校正文本、讲解 | 私有云端笔记；输入/校正文和上下文交给 DeepSeek 生成讲解 | 网站内容及用户提供内容，按后台实际选项核对 |
| 页面标题、清理后的 URL | 用户确认提交的笔记来源；移除 URL 用户信息、查询串及片段，保留路径 | 建议披露网页历史/访问 URL，并解释仅保存学习笔记来源，不持续采集浏览历史 |
| 确认后的截图/本地选图 | Supabase 私有 Storage 保存；DeepSeek 识别 | 网站内容/图片；图片可能包含用户主动提交的其他信息，不能宣称所有图片均无个人内容 |
| 请求状态、时间、模型用量、数值耗时 | 幂等、故障恢复、诊断与用量展示 | 结合后台类别说明技术使用数据；遥测仅接受数值耗时，不记录学习正文 |
| 字体、讲解模式与语言、每日复习数量 | 保存账号偏好 | 用户偏好/交互数据，按后台类别核对 |
| 学习点复习轮次、完成时间、下次到期日和已记住状态 | 安排间隔复习、避免重复，按账号保存 | 用户偏好/交互数据，按后台类别核对；单条笔记删除后可保留学习点进度，账号删除时清除 |

扩展不收取支付卡信息、不处理付款。DeepSeek 费用由其直接收取；不能因此把 Key 或用量相关处理从披露中省略。

配套PWA还处理用户主动启用的Web Push订阅、复习批次与打开状态，并共用上述学习点进度；同一隐私政策已覆盖学习中心。收到通知或打开卡片不推进复习轮次。这些不是扩展申请`notifications`权限的行为。

## 容易误写的边界

- 截图实现会先在本地内存捕获可见视口，再裁剪；只把用户预览确认后的区域上传。不要写成 Chrome 仅捕获了选区。
- 正文提交会附带自动取得的上下文及来源。只写“上传用户输入”不完整。
- 附近句子最多约 1500 字符；局部查找不等于上传整页文本。
- 点击发音使用浏览器/系统语音，优先本地 voice，但允许可用的远程 voice。不要承诺所有音频完全离线。
- 退出登录清除设备草稿与会话，不删除云端记录。单条删除会移出复习；截图由服务端清理。既有备份和已发送通知不追溯删除。
- 当前没有公开账号注销 UI；正式政策必须提供实际可用的账号删除/支持流程，不能虚构按钮或保留期限。
- 当前 JavaScript、字体和图标均随扩展包提供；模型结果按结构化数据渲染，不执行模型生成的 HTML/JavaScript。因此当前包的“远程代码”回答建议为“不使用”，上线前仍需核对最终产物。
- 不出售数据、不用于广告、Limited Use 等后台承诺须由发布者对实际服务运营确认后勾选，不能由此次源码检查代为认证。
