模型 Key 与费用

当前只支持 DeepSeek API，需要在连接设置中填写自己的 API Key，并确保厂商账号额度可用。模型费用由 DeepSeek 直接收取；ChatGPT、Codex 或 WorkBuddy 的订阅不抵扣这些 API 费用。重新讲解或重新识别可能再次计费。

快速模式通常等待更短；思考模式可能更慢、用量更多，也可能出错。每日精选使用已保存的讲解，不为每次复习重新调用模型。AI 的释义、假名或例句仍需要你核对。

iPhone 接收复习通知

  1. 使用支持网页推送的 iOS 版本（16.4 或更新），在 Safari 打开学习中心。
  2. 通过“分享 → 添加到主屏幕”安装，再从主屏幕图标打开并登录。
  3. 进入“设置”，开启每日精选和手机通知，同意系统通知权限；然后点击“发送测试通知”。

每天北京时间 07:00 起，按设置的每日数量安排到期卡片（默认 5 张，可输入 1–100 张）。数量修改对新生成的批次生效；没有到期内容不发空提醒。云端任务不要求电脑开机，但实际送达仍取决于网络、系统通知设置及推送服务。每个账号使用一台主要通知设备。

读完后点“已复习”才安排下一轮，收到通知或打开卡片不会推进。默认采用第 1、3、7、14、30 天的间隔节奏；延迟完成时，下一轮从实际完成日再间隔 2、4、7、16 天，不在一天补多轮。这个节奏不是对个人遗忘速度的精确预测。已记住的词汇或语法可点“已记住”停止复习，也可在完整讲解中撤销。

没有收到通知时，先从主屏幕打开应用，检查复习和通知开关，再检查 iPhone 的通知权限、专注模式和网络。测试成功表示当次链路可用，不保证后续每条通知都按时送达。

讲解失败或结果不确定

先检查连接、Key 状态及 DeepSeek 额度，再从历史打开原记录核对状态。断线或超时后，不要连续点击重试：原请求可能已产生费用。已经保存的材料可从历史核对；发起重试前请确认当前状态。

反馈时可提供发生时间、扩展版本、设备和浏览器版本，以及界面错误代码。截图请先遮住学习内容、来源地址和账号信息；不要发送密码、API Key、会话令牌或一次性链接。

删除记录、Key 或账号

历史列表可删除单条记录；设置中可移除托管 Key。退出登录或卸载不等于删除云端账号。移除托管 Key 也不会在 DeepSeek 平台撤销原 Key。

整套账号删除目前由管理员处理。请向 wenbinyin@gmail.com 提出申请并说明范围；管理员会核对归属、反馈处理结果。请勿在公开 GitHub Issue 中提交个人数据。保留范围和限制见隐私说明。
