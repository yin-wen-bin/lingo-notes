# Pronunciation icon

`pronunciation.png` is the pronunciation icon requested by the user, sourced from the rendered Youdao Dictionary page on 2026-11-13. It is bundled locally; displaying it makes no request to Youdao. The speech audio continues to use the browser/system speech service.

## History interface icons

`ui/search.svg`, `ui/trash.svg` and `ui/image.svg` are Heroicons v2.2.0 24px outline icons (`magnifying-glass`, `trash`, `photo`) by Tailwind Labs, Inc., under the MIT license. Their geometry is unchanged; the stroke is set to the interface's muted green. Upstream: https://github.com/tailwindlabs/heroicons/tree/v2.2.0/optimized/24/outline . The original license is bundled as `ui/HEROICONS-LICENSE.txt`. Icons are local assets and make no external requests.

`ui/capture.svg` is the same release's `viewfinder-circle` outline icon, downloaded from https://raw.githubusercontent.com/tailwindlabs/heroicons/v2.2.0/optimized/24/outline/viewfinder-circle.svg . Only its stroke color is set to the existing muted green; the upstream geometry and MIT license are retained.
